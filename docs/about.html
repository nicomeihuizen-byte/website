~/how we ship

Fast, with the brakes still on.

Speed from AI is only worth something if the process catches what AI gets wrong. So every change runs the same route, whether it is a typo or a new agent. No exceptions for "small" ones.

● pipeline · branch → main✓ all checks passed · deployed
  1. branchEvery change on its own branch. Main is never edited directly.
  2. pull requestDescribed, linked to the why, readable a year later.
  3. ci: scan + testsCodeQL security scan and unit tests on every push and pull request.
  4. ci: evalsFritz answers his trap questions on every preview deploy. Red means no merge.
  5. human reviewNico reads the diff. Nothing merges unread.
  6. cd: deployMerge to main ships it. No hand-copied files.
  7. monitorPublic status page. If it breaks, you see it too.

CodeQL · this sitenpm test · agent-fritz-guardrails, every pushFritz evals · every Vercel deployESLint + Next.js build · Fivesite diagnostics · SEO and security sweep

git
Everything in version control

Code, prompts, evals and site copy. If it is not in Git, it does not exist.

ci/cd
Green checks or no release

A red check on a preview means it does not merge. Nobody overrides it to make a deadline.

evals
Agents are tested like code

A fixed set of trap questions every agent has to pass before a change goes out.

secrets
Keys never touch the repo

Credentials live in the hosting platform's settings, per environment.

gdpr
EU data, written down

A privacy page that says what is kept, how long, and who to ask to delete it.

open
Proof in public

Fritz's guardrails and test harness are a public repo. Read the tests yourself.

~/how I work with AI

A tool. A very good one.

  1. 01
    It is a tool, not the workA model on its own produces nothing a client can use. The result comes from the workflow around it.
  2. 02
    Pipelines beat promptsOne prompt is a gamble. Controlled inputs and repeatable steps are a production method.
  3. 03
    Default output is a draftIt ships when it survives review, not when it compiles.
  4. 04
    Know where it breaksEvery model fails somewhere. Knowing where decides whether AI is the right tool at all.
  5. 05
    The model does not decide what is goodIt widens what one person can build. The judgement stays human.
