Site de Portefólio

Um portefólio responsivo inspirado em terminal, construído a partir de uma pequena stack estática, com um design de interação prático e controlos de segurança tratados como parte do produto.

// resumo

Interface de portefólio inspirada em terminal

O site apresenta o percurso profissional, os trabalhos selecionados, a informação de contacto e a documentação de projetos numa interface focada e inspirada em terminal. A página inicial inclui uma sequência de escrita consciente da sessão, cartões de projeto responsivos e navegação direta para o trabalho ativo.

Pequenos comportamentos de JavaScript com limites claros

JavaScript vanilla alimenta a sequência de escrita, a validação de formulários, as lightbox de projeto responsivas, a limpeza de imagens, o fecho por teclado e o bloqueio do deslocamento da página. O comportamento partilhado reside em scripts externos da mesma origem, em vez de ser duplicado entre páginas.

Boas práticas de segurança como funcionalidade

Cada página tem uma Content Security Policy restritiva, com uma política de resposta no momento da implementação em _headers. O site elimina análises de terceiros não fixadas, evita a construção insegura de HTML, valida a entrada de contacto, rejeita submissões de honeypot e utiliza um destino mailto fixo em vez de um POST de formulário entre sites.

Apresentação responsiva e acessível

Cabeçalhos semânticos, alternativas descritivas de imagens, lightbox compatíveis com teclado, estados de foco visíveis, alvos táteis para dispositivos móveis e recortes de imagem centrados com CSS mantêm a experiência utilizável em todos os tamanhos de ecrã.
