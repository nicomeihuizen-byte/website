~/vision

Uw volgende koper leert u kennen via een agent.

Die agent leest uw site, vergelijkt u met drie anderen en geeft antwoord voordat iemand de telefoon pakt. Hij antwoordt ook als u hem niets hebt gegeven om mee te antwoorden. De meeste bedrijven hebben dat nog niet door. De agent maakt dat niet uit.

Daar volgen twee dingen uit. Bedrijven moeten leesbaar zijn voor de machines die nu de eerste inkoopronde doen. En één senior met agents heeft het bereik waar vroeger een afdeling voor nodig was. Wij bouwen voor allebei: sites en data die agents goed lezen, en agents die echt werk doen.

~/how we ship

Snel, met de rem er nog op.

Snelheid dankzij AI is alleen iets waard als het proces opvangt wat AI fout doet. Daarom volgt elke wijziging dezelfde route, of het nu om een typfout gaat of om een nieuwe agent. Geen uitzonderingen voor "kleine" wijzigingen.

● pipeline · branch → main✓ alle checks geslaagd · uitgerold
  1. branchElke wijziging op een eigen branch. Main wordt nooit rechtstreeks bewerkt.
  2. pull requestBeschreven, gekoppeld aan het waarom, over een jaar nog leesbaar.
  3. ci: scan + testsCodeQL-securityscan en unittests bij elke push en elk pull request.
  4. ci: evalsFritz beantwoordt zijn strikvragen bij elke preview-deploy. Rood betekent: geen merge.
  5. menselijke reviewNico leest de diff. Niets wordt ongelezen gemerged.
  6. cd: deployEen merge naar main zet het live. Geen met de hand gekopieerde bestanden.
  7. monitorOpenbare statuspagina. Gaat er iets stuk, dan ziet u het ook.

CodeQL · deze sitenpm test · agent-fritz-guardrails, bij elke pushFritz evals · bij elke Vercel-deployESLint + Next.js build · Fivesitediagnose · SEO- en securitycontrole

ci/cd
Groene checks of geen release

Een rode check op een preview betekent dat er niet gemerged wordt. Niemand overrulet dat om een deadline te halen.

evals
Agents worden getest als code

Een vaste set strikvragen waar elke agent doorheen moet voordat een wijziging live gaat.

  1. 01
    Het is een tool, niet het werkEen model op zich levert niets op waar een klant iets mee kan. Het resultaat komt uit de workflow eromheen.
  2. 02
    Pipelines winnen van promptsEén prompt is een gok. Gecontroleerde input en herhaalbare stappen zijn een productiemethode.
  3. 03
    Standaardoutput is een conceptHet gaat live als het de review doorstaat, niet als het compileert.
