Ligt het aan ons of aan de leverancier?

Eerst onze diensten, dan de leveranciers waarop ze draaien. Onze eigen monitor controleert elke minuut. De lampjes en meldingen van leveranciers komen van hun eigen openbare statuspagina, gelinkt in elke rij, zodat u het zelf kunt nakijken.

~/our services

Vijf diensten, elke minuut in de gaten gehouden.

Vijf diensten worden bewaakt: de website (draait op GitHub Pages), Agent Fritz (Anthropic Claude API, Vercel, GitHub Pages; livechat via Upstash, afspraken via Google Workspace, leads via Proton Mail en Telegram, dat geen eigen statuspagina publiceert), het contactformulier en aanvragen (Vercel, Proton Mail), Five (UpCloud, Mistral AI, regio Frankfurt) en Second Audience-scans (OpenAI, Anthropic, Google Gemini, Perplexity; een storing bij een leverancier kan een rapport vertragen, niet breken). De live lampjes laden hier vanuit onze monitor.
