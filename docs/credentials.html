~/machine-readable

The same facts, for machines.

The same facts as JSON-LD in the head of this page, so an agent does not have to infer them from prose. sameAs is the load-bearing line: it states that this page and the profiles elsewhere carrying my name are one person. This is the layer that fails quietly on most sites.

{
  "@context": "https://schema.org",
  "@type": "ProfilePage",
  "mainEntity": {
    "@type": "Person",
    "name": "Nico Meihuizen",
    "jobTitle": "AI-native software engineer",
    "sameAs": [
      "https://www.linkedin.com/in/nico-meihuizen/",
      "https://github.com/nicomeihuizen-byte"
    ],
    "worksFor": [ { "@type": "OrganizationRole",
      "roleName": "Sr. Enterprise Account Executive Benelux",
      "startDate": "2022-03", "endDate": "2025-08",
      "worksFor": { "@type": "Organization", "name": "Minitab" } }, ... ]
