Site portfolio

Un portfolio responsive inspiré du terminal, construit à partir d'une petite stack statique, avec une conception d'interaction pratique et des contrôles de sécurité traités comme faisant partie du produit.

// aperçu

Interface portfolio inspirée du terminal

Le site présente le parcours professionnel, les projets sélectionnés, les coordonnées et la documentation des projets dans une interface ciblée inspirée du terminal. La page d'accueil comprend une séquence de frappe consciente de la session, des cartes de projet responsives et une navigation directe vers le travail actif.

De petits comportements JavaScript aux limites claires

Le JavaScript vanilla pilote la séquence de frappe, la validation de formulaire, les lightbox de projet responsives, le nettoyage des images, la fermeture au clavier et le verrouillage du défilement de la page. Le comportement partagé réside dans des scripts externes de même origine plutôt que d'être dupliqué sur plusieurs pages.

Les bonnes pratiques de sécurité comme fonctionnalité

Chaque page porte une Content Security Policy restrictive, avec une politique de réponse au moment du déploiement dans _headers. Le site supprime les analyses tierces non épinglées, évite la construction HTML non sécurisée, valide les entrées de contact, rejette les soumissions de type honeypot, et utilise une destination mailto fixe plutôt qu'un POST de formulaire cross-site.

Une présentation responsive et accessible

Des titres sémantiques, des alternatives d'image descriptives, des lightbox adaptées au clavier, des états de focus visibles, des cibles tactiles mobiles et des recadrages d'image centrés en CSS maintiennent l'expérience utilisable sur toutes les tailles d'écran.
