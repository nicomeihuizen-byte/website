~/machine-readable

Les mêmes faits en JSON-LD dans l'en-tête de cette page, pour qu'un agent n'ait pas à les déduire de la prose. sameAs est la ligne porteuse: elle établit que cette page et les profils ailleurs portant mon nom sont une seule personne, et c'est la seule partie de cette affirmation sur laquelle une machine peut agir.
