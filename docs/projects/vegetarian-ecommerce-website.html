Vegetarian Ecommerce Website

A focused ecommerce experience for discovering vegetarian products, making considered choices, and moving smoothly from browsing to checkout.

// overview

Buuf Louise was a vegetarian food delivery startup platform offering weekly neighborhood meal delivery through a secure e-commerce website.

I designed and developed the website, managed the hosting environment, handled order processing, and maintained the system using HTML, JavaScript, Python, and SQL, with integrated security and payment functionality. From start to finish, turnaround time of 3.5 months for the entire project
