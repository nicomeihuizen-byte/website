Portfolio Website

A responsive terminal-inspired portfolio built from a small static stack, with practical interaction design and security controls treated as part of the product.

// overview

Terminal-inspired portfolio interface

The site presents professional background, selected work, contact information, and project documentation in a focused terminal-inspired interface. The homepage includes a session-aware type sequence, responsive project cards, and direct navigation to the active work.

Small JavaScript behaviors with clear boundaries

Vanilla JavaScript powers the typing sequence, form validation, responsive project lightboxes, image cleanup, keyboard dismissal, and body-scroll locking. Shared behavior lives in external same-origin scripts rather than being duplicated across pages.

Security best practices as a feature

Every page carries a restrictive Content Security Policy, with a deploy-time response policy in _headers. The site removes unpinned third-party analytics, avoids unsafe HTML construction, validates contact input, rejects honeypot submissions, and uses a fixed mailto destination instead of a cross-site form POST.

Responsive, accessible presentation

Semantic headings, descriptive image alternatives, keyboard-friendly lightboxes, visible focus states, mobile touch targets, and CSS-centered image crops keep the experience usable across screen sizes.
