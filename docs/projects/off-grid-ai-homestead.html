One Acre, Zero Dependency

Off-grid, AI-driven farming on two plots 2,256 km apart: Prora through summer, Castelo Branco through winter.

A solar-powered field module (Birdbox) collects soil and local weather data. Through the Open-Meteo historical archive API (2006-2026) we bring in twenty years of regional weather history. Eurostat Agriculture Statistics adds regional yield figures, coarse ones though: annual, per hectare and per region, not per bed. The Thun calendar supplies a planting and harvesting calendar based on the position of the moon. This project computes it correctly and tests it, instead of assuming it.

The calculations run in Python. A locally running model (ML/LLM) lays the results side by side and predicts which vegetables and crops give the best yield per planting, when to sow them, and which rotations work best on a small field of 4,000 m².

The aim of this project is to give farmers, hobby growers and families something to hold on to, so they can grow organically at small and large scale, responsibly and successfully, on modern technique and age-old concepts that protect the earth.

The question

How much of a small farm's daily decision-making can genuinely off-grid AI handle end to end, from sensor to scheduler?

That is the whole project. Two plots on opposite sides of Europe, worked in alternation, documented publicly through 2026 and 2027. The full write-up, the ADRs and the data sources are in the repo.

// commitments

Three things this project does not compromise on

  1. 1 · Off-grid means off-grid. No cloud LLM in the daily loop.
  2. 2 · Every number carries its provenance and its error bars. A €30 sensor claiming ±0.3 pH does not get to report pH to one decimal.
  3. 3 · The biodynamic calendar is a hypothesis under test, not a scheduling rule.

// data

Two plots, two weather services

Prora leans on DWD Arkona, 33 km away, with measured radiation from 1947. Castelo Branco has no equivalent open history and leans on ERA5-Land. That asymmetry is not papered over.

// the calendar

The Thun calendar, honestly implemented

The evidence does not support the trigon effect. The calendar is therefore logged as a covariate and tested, never used as a rule.

// models

The LLM proposes, Python disposes

Every number is computed in tested Python. The model selects, prioritises and explains, and returns JSON validated against a schema. What it is aimed at: yield per square metre.
