Sito E-Commerce Vegetariano

Un'esperienza e-commerce mirata per scoprire prodotti vegetariani, fare scelte consapevoli e passare senza intoppi dalla navigazione al checkout.

// panoramica

Buuf Louise era una piattaforma startup di consegna di cibo vegetariano che offriva consegna settimanale di pasti di quartiere tramite un sito e-commerce sicuro.

Ho progettato e sviluppato il sito, gestito l'ambiente di hosting, curato l'elaborazione degli ordini e mantenuto il sistema utilizzando HTML, JavaScript, Python e SQL, con funzionalità di sicurezza e pagamento integrate. Dall'inizio alla fine, il tempo di realizzazione dell'intero progetto è stato di 3,5 mesi.
