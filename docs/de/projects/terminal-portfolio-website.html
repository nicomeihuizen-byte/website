Portfolio-Website

Ein responsives, terminal-inspiriertes Portfolio aus einem kleinen statischen Stack, mit praktischem Interaktionsdesign und Sicherheitskontrollen, die als Teil des Produkts behandelt werden.

// überblick

Terminal-inspirierte Portfolio-Oberfläche

Die Website präsentiert beruflichen Werdegang, ausgewählte Arbeiten, Kontaktinformationen und Projektdokumentation in einer fokussierten, terminal-inspirierten Oberfläche. Die Startseite enthält eine sitzungsbewusste Tippsequenz, responsive Projektkarten und direkte Navigation zur aktuellen Arbeit.

Kleine JavaScript-Verhaltensweisen mit klaren Grenzen

Vanilla JavaScript steuert die Tippsequenz, Formularvalidierung, responsive Projekt-Lightboxen, Bildbereinigung, Tastaturschließung und die Sperrung des Seiten-Scrollens. Geteiltes Verhalten liegt in externen Skripten derselben Herkunft, statt über Seiten hinweg dupliziert zu werden.

Sicherheits-Best-Practices als Feature

Jede Seite trägt eine restriktive Content Security Policy, mit einer Antwortrichtlinie zur Deployment-Zeit in _headers. Die Website entfernt nicht fixierte Drittanbieter-Analytics, vermeidet unsichere HTML-Konstruktion, validiert Kontakteingaben, lehnt Honeypot-Einreichungen ab und verwendet ein festes Mailto-Ziel statt eines Cross-Site-Formular-POST.

Responsive, barrierefreie Präsentation

Semantische Überschriften, beschreibende Bildalternativen, tastaturfreundliche Lightboxen, sichtbare Fokuszustände, mobile Touch-Ziele und CSS-zentrierte Bildausschnitte halten die Erfahrung über alle Bildschirmgrößen hinweg nutzbar.
