One Acre, Zero Dependency.

Autarke, KI-gesteuerte Landwirtschaft auf zwei Flächen, 2.256 km voneinander entfernt: Prora über den Sommer, Castelo Branco über den Winter. Eine Frage: Wie viele der täglichen Entscheidungen eines kleinen Hofs kann wirklich netzunabhängige KI übernehmen, vom Sensor bis zum Planer?

Zwei Flächen, eine Saison

Prora läuft durch den Sommer, Castelo Branco durch den Winter. Zusammen gibt es keinen Monat, in dem nichts wächst.

Nichts verlässt den Acker

Sonne, Sensor, Laptop, Plan. Das Modell läuft lokal; nur so übersteht das Off-Grid-Versprechen den Kontakt mit einer Rechnung.

Das Modell denkt, Python lenkt

Jeder Vorschlag durchläuft ein deterministisches Regelwerk, bevor er zur Aufgabe wird. Was an den Regeln scheitert, wird verworfen, und das Verwerfen wird protokolliert.

~/what it does

Sensor, Historie, Kalender, Modell.

Ein solarbetriebenes Feldmodul (Birdbox) erfasst Boden- und lokale Wetterdaten. Das historische Archiv von Open-Meteo liefert zwanzig Jahre regionales Wetter. Eurostat liefert regionale Ertragszahlen, und zwar grobe: jährlich, pro Hektar, pro Region, nicht pro Beet. Der Thun-Kalender liefert einen mondbasierten Aussaatkalender, den dieses Projekt korrekt berechnet und testet, statt ihn einfach vorauszusetzen.

Die Berechnungen laufen in Python. Ein lokales Modell legt die Ergebnisse nebeneinander und schlägt vor, welche Kulturen pro Pflanzung den besten Ertrag bringen, wann gesät wird und welche Fruchtfolgen auf 4.000 m² funktionieren.

Das Ziel: etwas, woran sich Landwirte, Hobbygärtner und Familien halten können, um in jedem Maßstab biologisch anzubauen, mit moderner Technik und uralten Konzepten, die die Erde schützen.

~/commitments

Drei Dinge ohne Kompromiss.

01

Off-Grid heißt Off-Grid.

Kein Cloud-LLM im täglichen Ablauf.

02

Jede Zahl trägt ihre Fehlerbalken.

Ein Sensor für 30 €, der ±0,3 pH angibt, darf den pH-Wert nicht auf eine Nachkommastelle genau melden.

03

Der Kalender ist eine Hypothese.

Der biodynamische Kalender wird getestet; er ist keine Planungsregel.

~/the field node

Ein Pico, kein Pi.

Tippen Sie auf ein Bild, um es in voller Größe zu sehen.

~/the calendar

Der Thun-Kalender, ehrlich umgesetzt.

Die Datenlage stützt den Trigon-Effekt nicht. Der Kalender wird deshalb als Kovariate erfasst und getestet, nie als Regel verwendet.

~/models

Das LLM denkt, Python lenkt.

Jede Zahl wird in getestetem Python berechnet. Das Modell wählt aus, priorisiert und erklärt, und es liefert JSON, das gegen ein Schema validiert wird. Was an den Regeln scheitert, wird verworfen, und das Verwerfen wird protokolliert. Das Ziel: Ertrag pro Quadratmeter.
