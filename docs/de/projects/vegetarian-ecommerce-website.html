Vegetarische E-Commerce-Website

Ein fokussiertes E-Commerce-Erlebnis, um vegetarische Produkte zu entdecken, bewusste Entscheidungen zu treffen und reibungslos vom Stöbern zur Kasse zu gelangen.

// überblick

Buuf Louise war eine Startup-Plattform für vegetarische Essenslieferung, die wöchentliche Nachbarschafts-Mahlzeitenlieferung über eine sichere E-Commerce-Website anbot.

Ich habe die Website entworfen und entwickelt, die Hosting-Umgebung verwaltet, die Bestellabwicklung übernommen und das System mit HTML, JavaScript, Python und SQL gepflegt, mit integrierter Sicherheits- und Zahlungsfunktionalität. Von Anfang bis Ende betrug die Durchlaufzeit für das gesamte Projekt 3,5 Monate.
