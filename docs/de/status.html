~/status

Liegt es an uns oder am Anbieter?

Erst unsere Dienste, dann die Anbieter, auf denen sie laufen. Unser eigener Monitor prüft jede Minute. Ampeln und Beschreibungen der Anbieter stammen von deren öffentlichen Statusseiten, in jeder Zeile verlinkt. Sie können also selbst nachsehen.

Wir fragen unseren Monitor ab…

Die Ampeln unten füllen sich, sobald er antwortet.

in Betrieb eingeschränkt oder verzögert ausgefallen unbekannt

Unser Statusmonitor ist gerade nicht erreichbar. Er läuft auf Vercel, wie Agent Fritz und das Kontaktformular; diese könnten also ebenfalls ausgefallen sein. Die Statusseiten der Anbieter unten funktionieren weiterhin. Für Dringendes: info(at)meihuizen.ai.

~/our services

Fünf Dienste, jede Minute überwacht.

Überwacht werden fünf Dienste: die Website (läuft auf GitHub Pages), Agent Fritz (Anthropic Claude API, Vercel, GitHub Pages; Live-Chat über Upstash, Terminbuchungen über Google Workspace, Leads per Proton Mail und Telegram, das keine eigene Statusseite veröffentlicht), das Kontaktformular und Anfragen (Vercel, Proton Mail), Five (UpCloud, Mistral AI, Region Frankfurt) und Second Audience Scans (OpenAI, Anthropic, Google Gemini, Perplexity; ein Ausfall beim Anbieter kann einen Bericht verzögern, aber nicht verhindern). Die Live-Ampeln lädt diese Seite von unserem Monitor.

~/vendors

Ihre eigenen Statusseiten.

Nur die Anbieter, über die Ihre Anfrage läuft, nicht jedes Tool, das wir nutzen. Telegram veröffentlicht keine eigene Statusseite und erscheint daher als unbekannt statt grün.

Ihre eigenen Statusseiten: GitHub · Vercel · Anthropic · Proton · Mistral AI · UpCloud · OpenAI · Google Cloud · Perplexity · Upstash · Google Workspace
